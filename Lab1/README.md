# Лабораторная работа №1.
# Задача
#### Написать программу на языке C++ для перемножения двух квадратных матриц, измерить скорость выполнения умножения в зависимости от размера матриц
# Решение
* #### 1.`Generator.cpp` - генерирует матрицы заданного размера, состоящие из случайных элементов заданного диапазона, записывает их размер и значения в файл `input.txt`
* #### 2.`Multiplication.cpp` - читает размер и значения матриц из `input.txt`, перемножает их в порядке циклов i-k-j, измеряет время выполнения операции умножения, выводит все полученные данные в файл `matrix_results.txt`
* #### 3.`Verify.py` - делает тоже самое, по пути запускает `Multiplication` и сравнивает результаты, затем записывает исход сравнения в matrix_results.txt
* #### 4.В файлах `input.txt` и `matrix_results.txt` находится пример работы этих програм.

#### Смотря на результаты измерений можно сделать вывод о том, что при увеличении размерности в два раза, время выполнения увеличится примерно в 8 раз.
#### $$T(N) \approx 8.044 \cdot 10^{-6} \cdot N^3 \text{ (мс)}$$
#### Этот факт напрямую подтверждает, что временная сложность классического алгоритма перемножения матриц равна O(N³) (кубическая сложность).
